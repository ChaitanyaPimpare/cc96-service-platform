# ServiceHub 🚀

A modern full-stack home services booking platform inspired by MakeMyTrip UI.

Users can signup/login, book services, and vendors can manage and deliver bookings through dedicated dashboards.

# ✨ Features

## Customer Features
- Customer Signup with OTP Verification
- Secure Login Authentication
- Browse Popular Services
- Book Services
- View Booking Status
- Responsive Dashboard

## Vendor Features
- Vendor Login
- View Incoming Bookings
- Accept Service Requests
- Mark Services as Delivered
- Vendor Analytics Dashboard

---

# 🛠 Tech Stack

## Frontend
- React.js
- Tailwind CSS
- Framer Motion
- React Router DOM
- React Hot Toast

## Backend
- Node.js
- Express.js
- Sequelize ORM
- PostgreSQL

- Vercel (Frontend)
- Render (Backend + Database)
